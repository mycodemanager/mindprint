# PRD Prose Review

**Style guide baseline**: Microsoft Writing Style Guide(中文文档适配:简洁、直接、避免冗余修饰)
**Reader type**: humans(alex + 下游 BMAD agents)
**Focus**: 影响 clarity 的问题——非风格偏好

> *只列出**会**实际阻碍理解 / 引起歧义 / 增加阅读成本的问题。intentional voice(如"破碎"、"画廊式翻看"等带感的隐喻表达)显式保留——这些是产品初心的语气载体,不是 prose 问题。*
